# Task 7: Reflection & Learning

During this assignment, I learned that HTML gives a webpage structure and meaning. Headings organize information, paragraphs hold text, links connect pages, and images add visual content. Semantic elements such as `header`, `main`, and `footer` make a page easier to understand. Connecting an external CSS file showed me how HTML and CSS work together: HTML describes content, while CSS controls its appearance and layout.

The most challenging topic was understanding how elements are sized and positioned, especially when combining the box model with Flexbox and Grid. At first, margin and padding seemed similar, but practicing with cards helped me see that padding is inside an element and margin is outside it. I enjoyed using Flexbox and Grid the most because they make it possible to arrange content neatly without complicated markup. I also liked adding media queries and seeing one page adapt to a phone screen.

HTML is the foundation of every webpage. It gives me a clear way to organize content before adding styles or interactivity. These skills will help me build accessible websites and understand how larger web projects are put together.
